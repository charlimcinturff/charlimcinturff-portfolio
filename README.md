# Charli McInturff — Engineering Portfolio

A black-and-white, archival/technical-report style portfolio for Charli McInturff,
Systems Engineering student at the College of Charleston.

## Structure

- `index.html` — portfolio content and layout
- `style.css` — responsive visual design
- `assets/traffic_system_poster.png` — MBSE / SysML project poster
- `assets/bayesian_swarm.png` — Swarm Intelligence project visualization

## GitHub Pages

1. Create or open the GitHub repository used for the portfolio.
2. Replace the existing site files with the contents of this folder.
3. Commit and push to the repository.
4. In GitHub, open **Settings → Pages** and make sure the deployment source is the repository branch/folder you use.

The site is static HTML/CSS and does not require a build process.
